How to install

  1. Tap Download for Android above.
  2. Open the downloaded therefore.apk (from the notification, or Files → Downloads).
  3. The first time, allow installs from this source when the phone asks, then go back.
  4. Tap Install. If Play Protect says it doesn't recognize the app, tap More details → Install anyway. It's only unrecognized because it isn't from the Play Store.

Updating later? Same button, same steps; the phone says Update. Your progress, streaks and stats stay.
